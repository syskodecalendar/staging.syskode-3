# Syskode service detail pages

The original export is retained. The only change to an existing page is a Know more link added to each of the 24 cards in project/Services.dc.html. Existing ERP and Zoho links are preserved.

24 new service-*.dc.html pages use the original Design Component format and the same support.js runtime. The new pages are registered in project/compat.json. All other original pages, scripts, styles and assets are unchanged.

## Opening the project

Use index.html through your existing exported-design workflow, then open Services. Each card now has a Know more link. The original export starts on Portfolio; this entry setting is preserved. The pages can also be served through HTTP with the original support runtime available.

## Interactions on each new page

- Three selectable use cases, explicitly presented as illustrative applications.
- Four selectable delivery stages, with previous/next controls.
- Expandable FAQs.
- Six selectable areas of interest and a clear-selection control.
- Open email draft creates a mailto link containing the selected interests; it does not send email or store a lead.
- Links to existing portfolio, company and service pages.

## Content

Content was written using the supplied Services page and Syskode’s public service categories, with additional proposed service detail suited to the business. No new customer testimonials, project results, delivery guarantees or certifications were invented. Scope, pricing and third-party costs are left for an agreed proposal.
